# 本地开发启动（Windows）

电脑重启后要自己把 MongoDB 和后端拉起来，它们不会自动开。

## 1. 启动 MongoDB

本机用的是便携版，不在 Windows 服务里，所以重启后会停。

```powershell
# 在任意目录执行
Start-Process -FilePath "D:\workspace\private-project\tools\mongodb\bin\mongod.exe" `
  -ArgumentList "--dbpath","D:\workspace\private-project\tools\mongodb\data",`
                "--logpath","D:\workspace\private-project\tools\mongodb\log\mongod.log",`
                "--bind_ip","127.0.0.1","--port","27017" `
  -WindowStyle Hidden
```

检查是否起来了：

```powershell
Test-NetConnection 127.0.0.1 -Port 27017
# TcpTestSucceeded 为 True 就说明通了
```

日志在 `D:\workspace\private-project\tools\mongodb\log\mongod.log`。

## 2. 启动后端

```powershell
cd D:\workspace\private-project\bp-miniapp\server
# 第一次：复制 .env.example 为 .env，填好 JWT_SECRET、DATA_KEY、WX_APPID、WX_SECRET
go run ./cmd/server
# 或直接跑已编译的：.\bp-server.exe
```

默认监听 `http://127.0.0.1:8080`，健康检查：浏览器打开 http://127.0.0.1:8080/healthz

Go 版本若低于 go.mod 要求，用我电脑交叉编译好的 `bp-server.exe`，或升级本机 Go。

## 3. 启动小程序前端

```powershell
cd D:\workspace\private-project\bp-miniapp\miniapp
npm install          # 只第一次需要
npm run dev:mp-weixin
```

用微信开发者工具打开 `miniapp\dist\dev\mp-weixin`。  
勾选「不校验合法域名」，本地才能访问 `http://127.0.0.1:8080`。

本地联调默认后端地址是 `http://127.0.0.1:8080`（见 `miniapp/.env.example`）。  
真机调试时改成电脑的局域网 IP，例如在 `miniapp/.env.local` 里写：

```
VITE_API_BASE=http://192.168.x.x:8080
```

生产构建用的是 `miniapp/.env.production` 里的 `https://bp.zeword.xyz`，不影响本地。

## 4. 常用顺序（重启后）

1. 启动 MongoDB（上面第 1 步）
2. 启动后端（第 2 步）
3. `npm run dev:mp-weixin` + 打开微信开发者工具

## 5. 停服务

- 后端：在跑 `go run` / `bp-server` 的窗口按 Ctrl+C
- MongoDB：结束 `mongod` 进程

```powershell
Stop-Process -Name mongod -Force -ErrorAction SilentlyContinue
```

## 出问题对照

| 现象 | 原因 | 处理 |
|------|------|------|
| 后端报连不上 Mongo | 重启后 mongod 没开 | 再跑第 1 步 |
| 小程序请求失败 | 后端没开 / 端口不对 | 确认 8080，开发者工具勾「不校验合法域名」 |
| 登录失败 | 要用微信开发者工具或真机，H5 登不了 | 看后端日志里的 code2session |
| 头像上传失败 | 合法域名没配 uploadFile | 公众平台加 `https://bp.zeword.xyz` |
