血压记录小程序 · 设计规范 v1.0

适用于 uni-app 微信小程序。两条底线：适老化（大字、大按钮、步骤少），数据中性展示（不分级、不评价、不画正常范围线）。

一、色彩规范

品牌色与渐变

品牌色#10C495主色、选中态、链接
渐变·主#34C9A3 → #62E17D主按钮、今日血压卡片
渐变·浅#70E8C9 → #A7FFB9页头背景、插画底
品牌浅底#E3F8F1图标底、选中标签背景

辅助色（只用于功能入口和装饰，不用于数据）

辅助绿#31CD4C希望-活力 · 打卡完成
辅助橙#FBA900温暖-关爱 · 家人共享、提醒入口
辅助蓝#37A5E6专业-高效 · 设置、隐私说明
页面背景#F4F7F6

字体用色

文字·强调#000000血压数值
文字·主#333333标题、正文
文字·次#666666说明、单位、时间
文字·弱#999999仅用于占位提示、禁用
使用约束：血压、心率数值和图表一律用黑色或品牌色，不按数值切换颜色；橙色、绿色不得用来表示"偏高""正常"等含义，也不画正常范围线。品牌绿上的白字对比度偏低，白字只用在 20px 以上的粗体；#999 不用于正文。

二、字体规范

字体：系统默认（iOS 苹方 / 安卓思源黑体）；数字可用 DIN Alternate，没有就退回系统字体。单位 rpx，750rpx = 屏宽，1px ≈ 2rpx。

层级大小字重用途示例
数值·超大128rpx（64px）700首页今日血压128/82
数值·大96rpx（48px）700录入框数字、历史详情128
大标题56rpx（28px）700页面问候、空状态下午好
标题40rpx（20px）600卡片标题、按钮今日用药
正文36rpx（18px）400列表、说明（最小正文）早上 08:00 · 1 片
辅助32rpx（16px）400时间、单位、Tab 文字（全局最小）mmHg

行高：正文 1.5，段落说明 1.6。全局不小于 16px；要跟随系统"大字体"设置放大，布局不能被撑破。

三、图标规范

线性图标，24×24 画板，描边 2px，圆角端点，颜色跟随文字（未选中 #999999，选中 #10C495）。功能图标放在 48×48、圆角 14 的浅蓝底块里。图标一律配文字，不单独用图标表达意思。点击区域不小于 88rpx×88rpx。

四、布局规范

项目规范
栅格与边距页面左右边距 32rpx（16px）；间距只用 8 的倍数：8 / 16 / 24 / 32 / 48rpx
卡片白底，圆角 40rpx（20px），内边距 40rpx，卡片间距 28rpx，阴影 0 4px 18px rgba(20,60,50,.06)
主按钮高 120rpx（60px），通栏，胶囊圆角，主色渐变；一屏只放一个主按钮
次按钮高 88rpx（44px），浅灰底或主色描边
点击区域所有可点元素不小于 88rpx × 88rpx，相邻可点元素间距不小于 16rpx
导航底部 3 个 Tab：首页 / 记录 / 我的；层级不超过 3 层；右上角给微信胶囊按钮留出位置
首页结构问候与日期 → 今日血压大卡片 → 记录按钮 → 今日用药 → 待办提醒
录入流程不超过 3 步：填高压/低压 → 选症状（可跳过）→ 保存；时间自动记录；默认弹出数字键盘
反馈保存、打卡后出现大号提示（≥ 2 秒）；删除和注销用二次确认弹窗，按钮写清动作，比如"删除这条记录"
文案短句、口语化；只描述功能，不写疗效（禁用"控制血压、降压、守护健康"等说法）
